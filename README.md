# 颜色容差定义实验台

打开 `index.html` 即可使用。

## 这个页面能做什么

1. **单基准色选取**：不再需要“对比色”，直接围绕一个基准色定义“同色范围”。
2. **可视化选色**：提供色轮 + 明度(V)滑块 + 颜色选择器。
3. **容差定义**：支持 4 类规则并可组合（AND逻辑）：
   - RGB通道容差（|ΔR|、|ΔG|、|ΔB|）
   - RGB欧式距离（$d=\sqrt{(ΔR)^2+(ΔG)^2+(ΔB)^2}$）
   - 感知差异 ΔE00（更接近人眼）
   - HSL方向容差（|ΔH|、|ΔS|、|ΔL|）
4. **区域可视化**：
   - 主色轮上叠加“容差命中区域”（当前明度V切片）
   - 色相-明度剖面图（固定当前饱和度S），用于立体感知容差
   - 容差范围卡片内新增“色轮命中区域”图
5. **范围与示例输出**：基于当前规则，生成可接受颜色范围（采样近似）与样例色块。
6. **定义导出**：输出 JSON 格式“同色定义”，可复制给后端或策略配置。

## 建议的产品规则起步值

- UI 常规色：`ΔE00 ≤ 6`，且 `|ΔR|/|ΔG|/|ΔB| ≤ 18`
- 品牌主色：`ΔE00 ≤ 3~5`，可再加 `|ΔH| ≤ 8`
- 容差偏大导致串色时：启用 HSL 约束，优先收紧 `|ΔH|`

## 说明

- “容差范围”部分是通过 RGB 网格采样得到的近似结果（默认步长 16）。
- 若需要更精细范围，可将脚本中的 `step` 改小（例如 8），但计算会更慢。
